# Blood Bank Management System

## Overview
The Blood Bank Management System is a web-based application designed to efficiently manage blood donation, storage, and distribution activities. The system helps maintain donor records, patient requests, blood inventory, staff details, and request approvals through a centralized database.

## Features

### Donor Management
- Register blood donors
- View donor details
- Manage donation records
- Track donor information

### Patient Management
- Register patients
- Manage blood requests
- Match patients with available blood groups

### Blood Inventory Management
- Track available blood units
- Monitor blood group availability
- Manage blood expiry dates

### Request Management
- Submit blood requests
- Approve or reject requests
- Track request status

### Staff Management
- Manage staff information
- Assign responsibilities
- Maintain staff records

## Technologies Used
- Frontend: HTML, CSS
- Backend: PHP
- Database: MySQL
- Web Server: Apache (XAMPP)

## Database Tables
- Donor
- Patient
- Blood Inventory
- Staff
- Request Access
